Используйте Anthropic-вариант для Claude Code, Anthropic SDK и аналогов. OpenAI-вариант (с /v1) работает с любым OpenAI-совместимым клиентом.

Шаг 1: Получите API ключ

Получите ключ sk-... у администратора. Проверить баланс и историю запросов можно на странице /balance.

Шаг 2: Подключите клиент

Установка в Claude Code CLI
  1. Скачиваем Claude Code CLI: npm install -g @anthropic-ai/claude-code
  2. Переходим в C:\Users\ваш_пользователь\.claude (на Mac/Linux: ~/.claude)
  3. Открываем settings.json и пишем туда:
{ "env": { "ANTHROPIC_BASE_URL": "...", "ANTHROPIC_AUTH_TOKEN": "ваш ключ", "ANTHROPIC_API_KEY": "ваш ключ", "ANTHROPIC_MODEL": "claude-opus-4-7" }, "effortLevel": "xhigh", "theme": "dark", "skipDangerousModePermissionPrompt": true }

Сохраняем файл и запускаем claude в любой папке проекта. Готово!

Anthropic SDK (Python)
import anthropic client = anthropic.Anthropic( base_url="...", api_key="ваш ключ", ) msg = client.messages.create( model="claude-opus-4-7", max_tokens=1024, messages=[{"role": "user", "content": "Привет"}], ) print(msg.content[0].text)
Anthropic SDK (Node.js)
import Anthropic from "@anthropic-ai/sdk"; const client = new Anthropic({ baseURL: "...", apiKey: "ваш ключ", }); const msg = await client.messages.create({ model: "claude-opus-4-7", max_tokens: 1024, messages: [{ role: "user", content: "Привет" }], }); console.log(msg.content[0].text);
OpenAI SDK (Python)

Любой OpenAI-совместимый клиент работает — просто укажите наш base_url с /v1.

from openai import OpenAI client = OpenAI( base_url="...", api_key="ваш ключ", ) resp = client.chat.completions.create( model="claude-opus-4-7", messages=[{"role": "user", "content": "Привет"}], ) print(resp.choices[0].message.content)
OpenAI SDK (Node.js)
import OpenAI from "openai"; const client = new OpenAI({ baseURL: "...", apiKey: "ваш ключ", }); const resp = await client.chat.completions.create({ model: "claude-opus-4-7", messages: [{ role: "user", content: "Привет" }], }); console.log(resp.choices[0].message.content);
Чистый HTTP запрос

OpenAI-совместимый формат:

curl .../chat/completions \ -H "Authorization: Bearer ваш_ключ" \ -H "Content-Type: application/json" \ -d '{ "model": "claude-opus-4-7", "messages": [{"role": "user", "content": "Привет"}] }'

Со стримингом (SSE):

curl -N .../chat/completions \ -H "Authorization: Bearer ваш_ключ" \ -H "Content-Type: application/json" \ -d '{ "model": "claude-opus-4-7", "messages": [{"role": "user", "content": "Привет"}], "stream": true }'
Cursor
  1. Открой Settings → Models
  2. В разделе OpenAI нажми Override OpenAI Base URL
  3. Вставь: ...
  4. В OpenAI API Key вставь свой sk-... ключ
  5. В списке моделей добавь claude-opus-4-7
Continue (VS Code / JetBrains)

В ~/.continue/config.json:

{ "models": [ { "title": "Aether Claude", "provider": "openai", "model": "claude-opus-4-7", "apiBase": "...", "apiKey": "ваш ключ" } ] }
aider

Через переменные окружения:

export OPENAI_API_BASE="..." export OPENAI_API_KEY="ваш ключ" aider --model openai/claude-opus-4-7

На Windows PowerShell:

$env:OPENAI_API_BASE = "..." $env:OPENAI_API_KEY = "ваш ключ" aider --model openai/claude-opus-4-7

Доступные модели

Endpoint поддерживает только две модели:

claude-opus-4-7 glm-5.1

Запросы к другим моделям будут отклонены с ошибкой 400.

Часто задаваемые вопросы

Какой URL использовать — с /v1 или без?

  • Без /v1 (Anthropic Base URL) — для Claude Code, Anthropic SDK, всего что говорит на нативном Anthropic API
  • С /v1 (OpenAI Base URL) — для OpenAI SDK, Cursor, Continue, aider, curl, любых OpenAI-совместимых клиентов

Как работает списание кредитов?

За каждый токен (вход + ответ) списывается 50 кредитов. Использование считается из поля usage.total_tokens в ответе модели. Историю запросов и баланс смотри на /balance.

Получаю "Invalid token" или 401

  • Используй кастомный ключ sk-... с этого endpoint, а не оригинальный Anthropic/OpenAI ключ
  • Проверь, что ключ скопирован полностью, без пробелов
  • Убедись, что Base URL указывает именно на этот сервис

Что делать, если закончились кредиты?

Свяжитесь с администратором — он пополнит баланс ключа в админ-панели. До пополнения запросы будут возвращать 402 Insufficient credits.

Стриминг работает?

Да, поддерживается SSE-стриминг через stream: true. Кредиты списываются по реальному usage.total_tokens в финальном чанке.

Как подключить Claude Code CLI к вашему endpoint

1 Установите Claude Code CLI

Скачайте и установите Claude Code CLI с официального сайта Anthropic или через пакетный менеджер:

npm install -g @anthropic-ai/claude-code
2 Настройте Claude Code CLI

Используйте ваш кастомный API ключ и Base URL:

# Linux/Mac
export ANTHROPIC_API_KEY="ваш-кастомный-ключ"
export ANTHROPIC_BASE_URL="..."

# Windows PowerShell
$env:ANTHROPIC_API_KEY="ваш-кастомный-ключ"
$env:ANTHROPIC_BASE_URL="..."
3 Запустите Claude Code CLI

Теперь вы можете запустить Claude Code CLI:

claude-code

Использование с OpenAI SDK

Вы также можете использовать стандартный OpenAI SDK:

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "...",
  apiKey: "ваш-кастомный-ключ",
});

const response = await client.chat.completions.create({
  model: "claude-opus-4-7",
  messages: [{ role: "user", content: "Hello" }],
});

console.log(response.choices[0].message.content);

Использование с curl

curl .../chat/completions \
  -H "Authorization: Bearer ваш-кастомный-ключ" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-opus-4-7","messages":[{"role":"user","content":"Hello"}]}'

Дополнительные команды

  • claude-code --help - показать справку по командам
  • claude-code --model claude-opus-4-7 - указать модель
  • claude-code --stream - включить стриминг ответов

Проверка баланса

Вы можете проверить баланс вашего API ключа на странице /balance. Просто введите ваш кастомный ключ и нажмите "Проверить баланс".

Часто задаваемые вопросы

Почему я получаю ошибку "Invalid token"?

Убедитесь, что:

  • Вы используете кастомный API ключ, созданный на этом endpoint
  • Ключ скопирован полностью без лишних пробелов
  • Сервер endpoint доступен

Как изменить модель?

Вы можете указать модель через флаг --model или в конфигурационном файле. Доступные модели: claude-opus-4-7, claude-sonnet-4-5 и другие.

Сколько кредитов тратится?

Кредиты тратятся в зависимости от количества токенов в запросе и ответе. Вы можете проверить текущий баланс на странице /balance.

Как увеличить лимит кредитов?

Свяжитесь с администратором endpoint для увеличения лимита кредитов на вашем ключе.

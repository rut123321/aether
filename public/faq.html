Шаг 1: Получите API ключ

Получите ключ у продавца.

Шаг 2: Установите Claude Code CLI

Если Claude Code CLI еще не установлен:

npm install -g @anthropic-ai/claude-code

После установки убедитесь, что команда доступна:

claude --version

Шаг 3: Настройте переменные окружения

Claude Code CLI использует переменные окружения ANTHROPIC_API_KEY и ANTHROPIC_BASE_URL. Вам нужно задать их перед каждым запуском или добавить в профиль shell.

Для Linux/Mac (bash/zsh):

export ANTHROPIC_API_KEY="ваш-скопированный-ключ" export ANTHROPIC_BASE_URL="..."

Для Windows (PowerShell):

$env:ANTHROPIC_API_KEY = "ваш-скопированный-ключ" $env:ANTHROPIC_BASE_URL = "..."

Для постоянной настройки добавьте export-строки в файл ~/.bashrc, ~/.zshrc или ~/.profile (Mac/Linux). На Windows добавьте через "Переменные среды" в настройках системы.

Шаг 4: Запустите Claude Code

После настройки переменных запустите:

claude

Или для запуска в конкретной директории:

claude /path/to/your/project

Claude Code CLI автоматически подключится к вашему endpoint через ANTHROPIC_BASE_URL.

Доступные модели

Наш endpoint поддерживает только две модели:

claude-opus-4-7 glm-5.1

Запросы к другим моделям будут отклонены. По умолчанию используется claude-opus-4-7.

Чтобы явно указать модель, используйте флаг --model:

claude --model claude-opus-4-7

Проверка баланса

Вы можете проверить оставшийся баланс кредитов вашего ключа на странице /balance. Введите ваш API ключ и нажмите "Проверить баланс".

Часто задаваемые вопросы

Почему я получаю ошибку "Invalid token"?

  • Убедитесь, что вы используете кастомный API ключ, созданный на этом endpoint, а не ключ от Anthropic
  • Ключ должен быть скопирован полностью, без пробелов в начале или конце
  • Проверьте, что ANTHROPIC_BASE_URL указывает на правильный endpoint

Что делать если закончились кредиты?

Свяжитесь с администратором endpoint для пополнения баланса вашего ключа. В админ-панели можно создать новый ключ или увеличить лимит существующего.

Как работает списание кредитов?

С каждого запроса списывается количество кредитов, пропорциональное количеству токенов в запросе и ответе. Подробная информация о расходе доступна после каждого ответа.

Можно ли использовать endpoint без Claude Code CLI?

Да. Endpoint поддерживает стандартный OpenAI-compatible API. Вы можете использовать любой клиент, который позволяет задать baseURL и apiKey, например OpenAI SDK, HTTP-клиенты или другие инструменты.
